# 17poker
## 概要
『LIAR GAME』に登場する「17ポーカー」を参考にした、ブラウザ上で遊べる非公式ファンメイドゲームです。
トランプは各スートのA,J,Q,K+ジョーカーの17枚を使用する。
## 流れ
「シャッフル」→「1stベット」→「手札交換」→「2ndベット」→「オープン」
上記を10ゲーム繰り返して、最終的にチップの枚数が相手より多いものが勝ちとなる。
## ルール
### ベットとチェックについて
- 各プレイヤーはベット時に「ベット」「レイズ」または「チェック」を宣言する。
- 
- 賭けるチップは1stベットでは5～15枚、2ndベットでは1stベットの枚数～30枚とする
- 両プレイヤーがチェックをした場合は、その回は不成立となり、場のチップはディーラーに回収される。
### 役の順位

1位：ファイブカード

2位：ロイヤルストレートフラッシュ

3位：フォーカード

4位：フルハウス

5位：ストレート

6位：スリーカード

7位：ツーペア

8位：ワンペア
